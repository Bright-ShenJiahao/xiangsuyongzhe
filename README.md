# 像素勇者

深夜两点，你还在打那台旧游戏机——屏幕一亮，人被吸进了游戏里。
像素风的幸存者类小游戏：勇者自动出手，你负责走位、翻滚，撑到首领出场并打倒它。

## 现在能玩的（沙盒对比）
主界面 → 选择武器（勇者之剑 / 回旋飞斧 / 火球术）→ 选择地图 → 战斗（升级三选一，2 分钟后首领出场）→ 结算。地图选择里有 3 个板块：
1. **勇者 · 打谷场**：帝国精进勇者 + 哥布林（《异世界幸存者》）。
2. **骑兵战场 · 原版手感**：《骑兵幸存者》的白马少年 + 4 名亲卫、无尽草原、波斯步兵 / 不死军 / 敌骑；转向惯性、越快越痛、满速撞飞，骑枪固定。
3. **骑兵素材 · 勇者玩法**：同样的骑兵素材和无尽地图，操作和武器和勇者一样。

## 文件
| 位置 | 内容 |
|---|---|
| `index.html`、`css/style.css` | 页面和界面样式（不用打包，改完直接刷新） |
| `js/data.js` | 武器、敌人、地图、升级的数值表 |
| `js/sprites.js` | 载入精灵图；黑描边换深褐、按地图调色、小兵三种人群色 |
| `js/battle.js` | 战斗（人物像素整数倍放大，地图高清垫底） |
| `js/ui.js` | 主界面（代码画的深夜房间）、选武器、选地图、HUD、升级、暂停、结算 |
| `js/cav.js` | 骑兵世界（板块 2、3）：无尽地面分块生成、八方向人马、亲卫楔形、两种手感 |
| `art/cav/` | 《骑兵幸存者》的素材：hero8 主角、comp8 亲卫、pcav8 敌骑、spara 波斯步兵、immortal 不死军、地面贴图、摆件 |
| `js/debug.js` | 网址带 `?debug` 出现调试按钮 |
| `art/hero/` | 勇者像素图集（帝国精进），由 `tools/pixel/build_atlas.py` 从 `art/src/` 的原图生成 |
| `art/goblin/` | 哥布林、刀手、弓手、哥布林王（来自《异世界幸存者》），`frames.json` 是每帧的脚底锚点 |
| `art/map/field.webp` | 牧场风像素打谷场 |
| `art/font/pixel.woff2` | 缝合像素字体子集（OFL），改了界面文字后跑 `python3 tools/font_subset.py` |
| `docs/pixel/` | 像素美术的出图提示词和参考图 |
