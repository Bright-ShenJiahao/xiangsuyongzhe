像素勇者 · 交互动效演示

每个格子点「播放」看效果。核对完告诉我哪些要、哪些改，再放进游戏。

1B震屏只给大伤害

左键「小伤」：只闪白+残影，不震。右键「大伤」（掉 15% 以上 / BOSS / 精英重击）：闪红边 + 震屏。

2捡东西飞向背包

捡到书或宝物：图标从地上弹起、划弧线飞进右上角暂停键，暂停键弹一下，亮起红点；左下角播报。

3铜钱滚动

捡到铜钱，数字从旧值滚到新值，每加一下跳一下。

4连击断裂

3 秒没杀到怪，连击数字抖一下，然后碎成像素块落下。

5踏板选定

站上去符文顺时针点亮；亮满一瞬间石板闪白 + 轻微震屏，表示"选定了"。

6B像素碎裂进门

画面裂成 8×8 方块，从门附近开始一圈圈被吸进黑洞；全黑后下一站的方块反向一块块拼回来。

7按 P 打开备战页

面板从下往上弹出（略带回弹），里面的格子一个接一个落下就位。

8装上技能

把书放进技能格：格子放大弹回，外面扩散一圈金光。

9升级

勇者脚下冲起一道金色光柱，头顶弹出 LEVEL UP，放大再回弹后上飘消失。

M2主界面按钮手感

鼠标移上去：按钮变亮、边框变金（告诉你"能点"）。按下：按钮往下沉一点，松手弹回（像真的按键）。你可以直接用鼠标试，或点播放看。

D勇者倒下（我选：基础 + GAME OVER 雪花）

① 最后一击：时间骤停、闪白、重震 → ② 慢动作：受伤后退 → 倒地小弹 + 尘土，画面褪灰（勇者留色）→ ③ 怪物围上，四角压黑成光圈缩到一点 → ④ 一阵游戏机雪花噪点，跳出抖动的 GAME OVER（呼应「被吸进游戏机」）→ 结算面板。选这个是因为它和开头「点击进入」的老电视关机是一套：进游戏是电视关机，死了是游戏机雪花。
