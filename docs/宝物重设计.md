# 宝物重新设计 + 现有数值速查（给 Codex 审核用）

> 11/26 草案。**只改 `DATA.startItems`（宝物）这一块的设计，不改装备、技能、誓约。** 第 2 节是游戏里现在的数值（从 `js/data.js` 导出，供对照）；第 3 节是新宝物表；第 4 节是请 Codex 重点审核的问题。

## 1. 分工原则

| 类别 | 管什么 | 例子 |
|---|---|---|
| 装备 | **数值成长**：伤害、防御、生命、智力、敏捷（铁剑→传说之剑等） | 铠甲、鞋子、腰带、配饰、武器 |
| 属性 | 力量/敏捷/智力/体魄/耐力 的基础换算 | 每点 +6% 伤害、+10 生命… |
| 誓约印记 | **技能出手的规则**（第几招、站定、翻滚后、连击）和 6 个身法 | 三击之誓、残影步 |
| **宝物（本次重做）** | **改变战斗/经济规则的小效果**，不加纯数值；带代价的「赌注型」保留 | 荆棘护符、守财奴戒指 |
| 兵器系宝物 | 技能 **突破** 的钥匙（Lv7 技能 + 对应宝物 → 再升一级）+ 一个与该系相关的特色效果，**不再写「某系伤害 +%」**（那是装备和熟练度的事） | 红枪缨、精灵弓弦 |

宝物同名合并升级，倍率 `oathLv = [1, 1.4, 1.7, 1.9, 2]`（Lv1–5），数值要保持低（后面还有 5 个阵营章节和无尽模式）。宝物栏 5 格（`gearSize = 5`）。
