## 0. 游戏概况与机制（审核前必读）

- 俯视角像素割草肉鸽（类吸血鬼幸存者），网页游戏，**PC 和手机竖屏**都要能玩。
- 第一章 9 站（第 8 站后出金门，第 9 站首领），每站打完选路线（战斗 / 精英 / 宝箱 / 篝火 / 商店 / 奇遇）。
- 玩家只控制**走位**和**翻滚**；技能**全自动**。
- 人物 4 名（阿远、小凛、戈拉斯尔、公主〔隐藏〕），属性基本一致，各带 1 个小特性；**靠武器和技能区分**，不选职业。
- 第一章敌人全是哥布林（约 21 种）。怪物体质：铁甲（物理减半）、灵体（物理减半、魔法 +25%）、魔抗（魔法减半）。

### 0.1 出手机制
- 技能槽 3 个，最多扩到 5 个，可**拖动排顺序**。技能**按顺序轮流**释放，**没有冷却**。
- 每个技能有前摇 wu、后摇 rc（秒）；单技能 DPS ≈ 伤害 ÷ (wu + rc)。持续类在持续期间按跳结算。
- 熟练度：每放一次 +1，7 级（门槛 8/20/36/56/80/110/150）；Lv3 / Lv5 / Lv7 各有一次形态变化。**Lv7 是技能最终形态**（取消了 Lv8 突破）。
- 品阶：初阶 / 中阶 / 高阶 / 宗师。射程单位为游戏像素，主角身高约 40。

## 1. 已定原则

1. 攻击形状学吸血鬼幸存者：大、好认、往外发散；不按武器现实长度只打身边。
2. 名字统一**西方奇幻味**，每个都有英文原型；不用武侠 / 日式 / 格斗游戏原招式名；不成套照搬暗黑 / 魔兽 / D&D 原名。**例外：游戏机光枪**（复古电子游戏通用术语，不用商标名和原样画面）。
3. **位移技能必须标【位移】**，并且**只沿玩家自己的移动方向**（不做后跳）；落点前 0.3 秒预警；不出地图、不上悬崖。设置里可切换「跟随移动方向（默认）/ 自动索敌」。枪的特色就是位移（一套技能槽里枪位移最多 3 个），其他武器 0～1 个。
4. **玩家技能不要频繁全屏震动、闪屏、整屏变色**（容易晕）；特效放在局部。受重击、击败首领偶尔震一下可以；残光步的 0.3 秒慢动作保留。
5. 每把武器技能数**不必一致**，符合特色即可。
6. 武器不放被动（被动归誓约）；不做蓄力操作；不做公主光环。
7. 魔法三类区分：元素（法杖）只伤害和控制；圣光（圣典）是唯一治疗 / 护盾 / 净化（例外：屠龙之誓保留回血）；黑暗（镰刀）是唯一吸血。
8. 伤害只分物理 / 法术；技能和怪物可带**多个属性标签**。
9. 每把武器一套「标记 → 引爆」联动，标记显示在怪头上。
10. 同一技能场上最多 1 个实例（再放刷新 / 替换）；每个技能写清占用时间、跳伤间隔、同目标命中上限；Lv3 不翻倍总伤；回复 / 吸血按整次释放封顶。

## 2. 系统

### 2.1 属性标签
- 物理：斩、刺、射；法术：火、冰、雷、奥术、圣光、黑暗、数码、毒。
- 任一标签命中弱点 ×1.5（不叠加）；只命中抗性 ×0.5；弱点优先。弱点伤害数字黄色放大，抗性灰色。第一章哥布林基本不设弱点。

### 2.2 怪物状态与标记
| 类 | 名称 | 规则 |
|---|---|---|
| 状态 | 点燃 / 流血 / 中毒 | 持续掉血，不暴击、不吸血 |
| 状态+标记 | 寒滞 → 冻结 | **只有冰系能挂寒滞**（其他减速不算）；叠满冻结；冻结后 2 秒不能再冻 |
| 标记 | 破绽（剑） | 叠 3 层，被引爆 |
| 标记 | 失衡（枪） | 浮空只是画面，同时挂 2.5 秒失衡；首领只挂失衡 |
| 标记 | 猎物（弓） | 弓技能优先打它，+25% |
| 标记 | 审判（圣典） | 叠 3 层满层自动落惩击 |
| 标记 | 诅咒（镰刀） | 易伤 10%，死后传给附近 1 只 |
| 计数 | 连击（光枪） | 玩家侧计数，每次释放首次命中 +1 层（+2%，最多 10 层），受伤 −5 层 |
- 头顶最多 3 个像素图标（标记 > 控制 > 持续伤害），叠层显示数字，引爆时闪一下。精英 / 首领控制时长减半。
- 融化爆炸：火打冻结的怪炸 10 并解冻，同一技能不重复触发。

### 2.3 全局属性上限（溢出时面板标橙「已达上限」，拿装备时也提示）
出手速度 +40%｜移速 +30%｜范围 +35%｜暴击率 35%｜暴伤 250%｜闪避 25%｜减伤 30%｜每秒回复（所有来源合计）1% 最大生命。基础暴击 5%、暴伤 150%。

## 4. 誓约（20）与身法（8）

**誓约**：3 个槽，**第 1 槽主修 100%，第 2、3 槽辅修 50%**；同名合并升级 ×1 / 1.4 / 1.7 / 1.9 / 2。

## 6. 转职（取代技能突破，是后期唯一大成长）

- **一转**：**同系两本 Lv7** 书 → 该系职业。两本书合进**一个槽位**（空出一槽），轮到时**两本照放，各多一个职业效果**；前后摇只算一次（取较长）。不同系不能一起转。
- 职业书有自己的熟练度（Lv1→7），职业效果逐级变强。
- **二转**：再同系两本 Lv7。若同系 → 两个同名职业（不升阶）。
- **最终职业**：两本职业书都满级 → 合成一本最终职业书（4 本原书照放，各带最终效果，再空一槽）。
