## 0. 游戏概况（审核前必读）

- **类型**：俯视角像素割草肉鸽（类《吸血鬼幸存者》），网页游戏，PC 和手机竖屏都要能玩。
- **流程**：主角带公主一站一站往前推。第一章 9 站，第 8 站后出金门，第 9 站首领哥布林王。每站打完选路线（战斗 / 精英 / 宝箱 / 篝火 / 商店 / 奇遇）。
- **操作**：玩家只控制**走位**和**翻滚**。技能全部**自动释放**，没有蓄力、没有瞄准。
- **人物**：4 名（阿远、小凛、戈拉斯尔、公主〔隐藏〕），属性基本一致，各带 1 个小特性。**区分靠武器和技能**，不选职业。
- **敌人**：第一章全是哥布林（约 21 种，含精英、小头目、首领）。怪物有体质：铁甲（物理减半）、灵体（物理减半、魔法 +25%）、魔抗（魔法减半）。

### 0.1 技能是怎么放的（影响平衡判断）
- 玩家有 **3 个技能槽，最多扩到 5 个**。技能**轮流**释放（槽 1 → 槽 2 → 槽 3 → 槽 1 …），**没有冷却时间**。
- 每个技能有 **前摇 wu**（秒）和 **后摇 rc**（秒），出手节奏 = 前摇 + 后摇。目标超出射程时跳过、轮到下一本。
- 所以：**单次伤害 ÷ (wu + rc) ≈ 该技能 DPS**；持续类（hold 秒）在持续期间反复结算。
- **熟练度**：每放一次 +1，7 格（门槛 8 / 20 / 36 / 56 / 80 / 110 / 150）。第 2/4/6 格伤害 +10%，Lv3 / Lv5 / Lv7 各有一次形态变化。
- **品阶**：初阶 / 中阶 / 高阶 / 宗师（越高越强，技能书掉落按品阶抽）。
- **单位**：射程 rg 用游戏像素，主角身高约 40。手机竖屏可视宽约 390。

## 1. 已定的设计原则

1. **攻击形状学吸血鬼幸存者**：大、好认、往外发散（投掷、远处落地、地面区域、扩散的波）。**不要**按武器的现实长度只打身边。
2. **名字统一西方奇幻味**（参考魔兽世界、暗黑破坏神、龙与地下城中文版）。不用武侠、日式、格斗游戏原作招式名。**唯一例外：游戏机光枪**（复古电子游戏术语）。
3. **每个技能名都要有英文原型**。
4. **会移动角色的技能必须标【位移】**；落点前 0.3 秒画预警；不出地图、不上悬崖；每把武器最多 1～2 个。
5. **玩家技能不要震屏、闪屏、整屏变色**（容易晕）。特效可以华丽，但只在局部。受重击、击败首领偶尔震一下可以。
6. **每把武器技能数量不必一致**，符合特色就行（法术类可以多）。
7. **武器不放被动**（被动交给“誓约”系统）。不做蓄力操作，不做公主光环。
8. **魔法三类严格区分**：元素（法杖）只伤害和控制、不治疗；圣光（圣典）是唯一能**治疗 / 护盾 / 净化**的；黑暗（大镰刀）是唯一能**吸血**的、靠怪死亡滚雪球。
9. **伤害只分物理 / 法术**，技能和怪物可以带**多个属性标签**（见第 3 节）。
10. **每把武器一套「标记 → 引爆」联动**，标记要在怪头上显示图标。

## 3. 系统

### 3.1 属性标签
- 物理：斩（剑、镰刀）、刺（枪）、射（弓）、钝（拳腿）。法术：火、冰、雷、奥术、圣光、黑暗、数码（光枪）、毒。
- 技能、怪物都可带多个标签。**任一标签命中弱点 ×1.5（不叠加）；只命中抗性 ×0.5；弱点优先。** 弱点伤害数字黄色放大，抗性灰色。
- 第一章哥布林基本不设弱点；第二章起：骷髅弱钝抗刺、冰元素弱火、亡灵弱圣光、史莱姆抗钝……

### 3.2 怪物状态与标记
| 类 | 名称 | 效果 | 来源 |
|---|---|---|---|
| 状态 | 点燃 | 持续掉血 | 法杖火系、圣水、炽天使 |
| 状态 | 流血 | 持续掉血，可叠 | 剑 |
| 状态 | 中毒 | 持续掉血 | 通用毒药、暗器、镰刀剧毒新星、弓荆棘 |

| 状态 | 眩晕 / 恐惧 / 混乱 | 控制 | 各处 |

- 精英 / 首领：控制类时长减半，标记正常。

### 3.3 尸体（镰刀用）
- 怪死后原地留像素骸骨 5 秒渐淡，同屏 ≤30 堆。（现在代码 1.3 秒就移除）
