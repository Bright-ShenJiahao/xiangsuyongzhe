# 技能数值卡

共8个技能池、92个技能。时间单位为秒；wu/rc为基础前摇/后摇。数字后的 \* 表示本次数值补设（含依赖补设的计算结果）；总伤与DPS均为本次数值卡计算值，统一加星号；DPS保留两位小数。

已有技能优先照抄 `js/data.js` 的 wu、rc、dmg、hold；与总设计第3节冲突时，同格保留设计值并标注来源，总伤与DPS按代码值计算。更名技能沿用原技能数据；没有明确对应关系的新技能不借用已删除技能。基础卡按未升级、无属性/装备/标记增伤、目标完整承受一次释放计算；条件附伤另列。单体总伤=各次命中伤害之和+收尾伤害；DPS=单体总伤÷(wu+rc)，不加持续时间。召唤类按要求伤害填0；斩杀、外部跟放、反弹不折算为固定伤害。

持续区域跳伤在每个间隔末结算，不在起点额外跳一次；连射、顺序落剑等离散攻击在起点发出首击；同时存在的分身共享所列同目标上限。瞬发持续时间用“瞬时”，无跳伤用“—”。段数是全次释放数量，命中上限是单目标数量。
