# 技能重设计（11/26 讨论记录）

## 最后审核清单（全部武器定完后逐项过）
1. **技能名字**：统一西方奇幻味；用词规则（风刃/剑芒/剑光、枪芒/龙息、箭/光箭）是否一致；同系内不撞字。
2. **技能平衡**：伤害、射程、冷却按品阶对齐；范围技与单体技的取舍；位移技能的风险。
3. **技能联动**：每把武器一套「标记 → 引爆」，标记要在怪头上显示图标；跨武器联动第二章再说。

## 已定原则
- 人物属性基本一致，各带一个特性；区分靠武器和技能。不做开局选职业。
- 第一章武器：剑、枪、弓、元素法杖、圣典、双手大锤；隐藏武器：游戏机光枪；镰刀以后。
- 法杖只留元素；圣光柱归圣典；暗影黑雾、深渊之门先下架。
- 通用技能：格斗空手、暗器（飞刀、飞镖、手里剑都算暗器）。
- 不做：武器里的被动（交给誓约）、公主光环、蓄力操作。技能全自动。
- 誓约、身法保持现状；候选（愤怒/吸血/交锋/回响；替身步/踏火步/护卫步/飞刃步）待定。
- **会移动角色的技能必须标【位移】**；落点前 0.3 秒画预警；不出地图、不上悬崖；每把武器最多 1～2 个。
- 攻击形状按吸血鬼幸存者：大、往外发散。

## 属性标签（已定方案 B）
- 伤害类型仍只有 物理 / 魔法（吃力量/敏捷/智力，和怪物体质 铁甲/灵体/魔抗 照旧）。
- 每个技能可带**多个**属性标签：物理系 斩（剑）、刺（枪）、射（弓）、钝（锤）；魔法系 火、冰、雷、奥术、圣光、黑暗。例：苍穹龙跃=刺+雷，炽天使之剑=圣光+火，大地崩裂 Lv5=钝+火。
- 怪物可带**多个**弱点 / 抗性标签。例：骷髅 弱钝 抗刺；冰元素 弱火；亡灵 弱圣光；史莱姆 抗钝。第一章哥布林基本不设，第二章起用。
- 待定：倍率与叠加规则（建议：任一标签命中弱点 ×1.5，不叠加；只有抗性时 ×0.5；弱点优先于抗性）；图鉴显示弱点、伤害数字变色。
- 注意：4 把物理武器 3 把吃力量，只有弓吃敏捷 → 平衡审核。

## 怪物标记系统（已同意，待实现）
- 两类：**状态**（点燃、流血、缓滞→冻结、眩晕、浮空，打上即生效）；**标记**（破绽、浮空、猎物、缓滞、易伤，专供引爆）。浮空、缓滞兼两类。
- 怪头顶像素图标最多 3 个，优先级 标记 > 控制 > 持续伤害；叠层显示层数；引爆时图标闪一下消失。
- 精英/首领：控制类时长减半，标记类正常。
- 美术：8～10 个 8×8 或 10×10 小图标，一张图做完。

## 魔法三类区分原则（已定）
| | 元素（法杖） | 圣光（圣典） | 黑暗（镰刀，以后） |
|---|---|---|---|
| 来源 | 操纵火冰雷 | 向神祈祷 | 从敌人身上夺取 |
| 手感 | 单纯破坏 | 打怪同时保护自己 | 越打越强、以命换命 |
| 独有 | 元素反应 | 自我治疗、护盾、净化 | 吸血、诅咒、怪死成资源 |
| 形状 | 落点、连锁、扩散 | 天降光柱、外放光环、十字光 | 贴近收割、地面暗影 |
| 状态 | 点燃、缓滞、冻结 | 审判标记（圣光增伤，死亡回血） | 诅咒（死后炸开传染） |
| 颜色 | 红蓝紫 | 金白 | 黑紫暗红 |
- 元素不治疗；治疗护盾只属圣光，吸血只属黑暗。圣光从天降或自身外放；黑暗靠怪死亡滚雪球。
- 法杖四系：火=炸和烧（伤害最高、无控制）；冰=控制保命（伤害最低）；雷=连锁随机，专引爆缓滞；奥术=稳定填充，无联动。
