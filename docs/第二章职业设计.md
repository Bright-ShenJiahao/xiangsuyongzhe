# 第二章职业设计（圣典系、镰刀系）— 草案，待确认

规则沿用 v2 审核结论：两本同系不同技能 Lv7 → 职业书；时间相加；每次释放对同一目标只触发 1 次；追加攻击不触发效果；回复计入「每 3 秒 3%」上限。
标记分工：审判 = 回血，诅咒 = 传染。

## 一转（2 个）

| 职业 | 英文 | 效果 |
|---|---|---|
| 圣光祭司 | Lightpriest | 每次释放首次命中挂 1 层审判；审判惩击时回复 0.5% 生命 |
| 亡灵术士 | Necromancer | 每次释放首次命中挂诅咒；带诅咒的怪死亡时召唤 1 只小骷髅（沿用骷髅同屏上限） |

## 最终职业（15 个）

| 组合 | 职业 | 英文 | 效果 |
|---|---|---|---|
| 圣+圣 | 圣光使徒 | Apostle of Light | 审判上限 3→5 层；惩击变为小范围圣光爆发 |
| 镰+镰 | 死亡领主 | Deathlord | 骷髅同屏上限 +2；骷髅攻击挂诅咒 |
| 圣+镰 | 暮光行者 | Twilight Walker | 审判惩击时，若目标带诅咒，诅咒立即传染 1 次 |
| 剑+圣 | 圣殿骑士 | Templar | 引爆破绽时挂 1 层审判 |
| 枪+圣 | 天枪骑士 | Sky Lancer | 位移结束时，对落点周围的怪挂 1 层审判 |
| 弓+圣 | 光羽射手 | Lightfeather Archer | 引爆猎物时审判 +1 层 |
| 法+圣 | 神谕法师 | Oracle | 每次元素反应，对该目标挂 1 层审判 |
| 光枪+圣 | 像素天使 | Pixel Angel | 连击 ≥10 时，惩击伤害 +50% |
| 通用+圣 | 光明斗士 | Radiant Brawler | 通用技能命中挂 1 层审判 |
| 剑+镰 | 血刃骑士 | Bloodblade Knight | 引爆破绽时，目标的诅咒传染 1 次 |
| 枪+镰 | 冥枪骑士 | Grave Lancer | 位移路径上的怪挂诅咒 |
| 弓+镰 | 幽冥射手 | Gloom Archer | 猎物死亡时召唤 1 只小骷髅 |
| 法+镰 | 死灵法师 | Deathcaller | 元素反应时，目标的诅咒传染 1 次 |
| 光枪+镰 | 幽灵玩家 | Ghost Gamer | 小骷髅改为射像素弹（各 3 伤） |
| 通用+镰 | 亡魂斗士 | Soulbound Brawler | 通用技能命中挂诅咒 |

总计：第一章 6 系 21 个最终职业 + 第二章 15 个 = 8 系 36 个。
