# 职业纹章设计（44 枚）— 草案

统一规格：盾形纹章，正面，像素风，透明底。
- 一转（8 枚）：银色盾框，中间一个主图案，带该系颜色。
- 最终职业（36 枚）：金色盾框，顶部加小王冠或双翼装饰，图案体现两系融合。

|---|---|---|---|
| 疾风剑士 | 剑 | 绿色旋风缠绕的直剑 | 绿 |
