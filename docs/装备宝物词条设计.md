# 装备 / 宝物 / 词条 设计（11/26；武器、上限、词条已审核通过，接技能重设计）

> 参考三国终章的装备词条系统、群侠传道具分类，但按像素勇者“一局肉鸽、装备只在当局有效”的规模做轻量版。
> 数值均为首轮草案。宝物同名合并倍率 m = 1 / 1.4 / 1.7 / 1.9 / 2。

## 0. 分工（不重复）

| 系统 | 管什么 | 不管什么 |
|---|---|---|
| 武器装备 | 该武器技能的**基础倍率**；传说级带 1 条武器专属特效 | 规则类效果 |
| 防具 5 槽 | 生命、防御、基础属性（力敏智体耐） | 增伤规则 |
| 词条 | 装备上随机出现的**小幅加成**，含标签增伤、挂标记几率 | 大机制 |
| 宝物 | **改变规则的小效果** / 赌注 / 经济 / 突破钥匙 | 纯数值（交给装备词条） |
| 誓约 | 出手规则、标记强化（主修 / 辅修） | — |
| 身法 | 翻滚改造 | — |

## 1. 属性上限（全局，借三国终章）

| 属性 | 上限 |
|---|---|
| 出手速度 | +40% |
| 移速 | +30% |
| 范围 | +35% |
| 暴击率 | 35% |
| 暴击伤害 | 250% |
| 闪避 | 25% |
| 减伤（受到伤害 −） | 30% |
| 每秒回复（所有来源合计） | 最大生命 1% |

- **溢出提醒**：属性超过上限时，属性面板里该项显示为橙色并标「已达上限」；捡到 / 买到会让某项溢出的装备、宝物时，卡片上提示「XX 已达上限，超出部分无效」。（PC / 手机都要显示）

基础暴击 5%、暴伤 150%。持续伤害（点燃、流血、中毒）不暴击、不吸血。

## 2. 武器装备（每把 3 阶，名字西幻化）

武器决定能学哪一系技能。每阶提高该系技能伤害倍率；**传说阶**多 1 条武器专属特效（和该武器的标记联动）。

| 武器 | 一阶（×1.00） | 二阶（×1.15） | 三阶·传说（×1.30 + 专属特效） | 传说专属特效 |
|---|---|---|---|---|
| 剑 | 铁剑 | 精钢剑 | 风之剑 Galeblade | 破绽引爆时，额外放出一道小风刃（引爆伤害 25%） |
| 枪 | 铁枪 | 精钢枪 | 雷龙枪 Stormdrake Lance | 位移技能结束时，落点劈下一道小雷（伤害 8） |
| 弓 | 木弓 | 复合弓 | 月影长弓 Moonshadow Bow | 猎物标记的怪死后，自动向最近的怪射 1 支追踪箭 |
| 元素法杖 | 木杖 | 秘银杖 | 元素之杖 Staff of Elements | 融化爆炸、寒滞连锁的范围 +30% |
| 光枪（隐藏） | 光线枪 | 改造光枪 | 终极光枪 Ultimate Zapper | 连击 ≥10 层时，每次放技能多射 1 发像素弹 |
| 圣典（第二章） | 祷文书 | 圣典 | 天启之书 Tome of Revelation | 审判满层自动惩击的范围 +50% |
| 大镰刀（第二章） | 收割镰 | 骸骨镰 | 冥王之镰 Reaper's Scythe | 诅咒传染时，被传上的怪受到 5 点暗影伤害 |

防具 5 槽（头盔 / 铠甲 / 腰带 / 鞋子 / 配饰）沿用现有 3 阶数值，不改。

## 3. 词条（装备随机附带）

规则：
- 一阶 0～1 条，二阶 1 条，三阶 2 条；同一件装备不重复同名词条。
- 每条 3 档（C / B / A），掉落概率 50% / 35% / 15%。
- 附魔石：给装备加 1 条词条或把一条升一档（沿用现有附魔石）。

| 类 | 词条 | C / B / A | 说明 |
|---|---|---|---|
| 基础（现有 5 条保留） | 暴击率 | +2 / +4 / +7% | |
| | 暴击伤害 | +8 / +16 / +28% | |
| | 出手速度 | +3 / +6 / +10% | |
| | 范围 | +3 / +6 / +10% | |
| | 对精英伤害 | +4 / +8 / +14% | |
| 标签增伤（新） | 火焰 / 寒冰 / 雷电 / 奥术 伤害 | +4 / +8 / +12% | 只加对应标签的技能 |
| | 斩击 / 穿刺 / 射击 伤害 | +4 / +8 / +12% | 剑 / 枪 / 弓 |
| | 数码 伤害 | +4 / +8 / +12% | 光枪，只在解锁后出现 |
| 标记（新） | 对带标记的怪伤害 | +3 / +6 / +10% | 任意标记都算 |
| 生存（新） | 闪避 | +1 / +2 / +4% | |
| | 移速 | +2 / +4 / +6% | |
| | 翻滚回格 | +3 / +6 / +10% | |
| 经济（新） | 铜钱获得 | +3 / +6 / +10% | |

共 **15 种**词条（标签增伤按种类分开算则 23 种）。「命中挂标记」只由宝物负责，词条不做。不做负面词条和特殊词条（太重）。

### 4.5 标记 / 状态（7，挂标记只在宝物里；词条只做「对带标记的怪增伤」，不重叠）
**挂标记（4）**：固定挂某一种，拿任何武器都能挂，用来做跨武器联动。每个技能每次释放最多触发 1 次，副弹 / 追加伤害不触发。

|---|---|

| 猎人徽章 | 技能命中 6%×m 几率挂猎物 |
| 寒玉坠 | 技能命中 6%×m 几率挂 1 层寒滞 |

**状态规则（3）**：不加伤害 %，只改机制。
| 宝物 | 效果 Lv1 |
|---|---|
| 蛇铃 | 中毒的怪死后炸开一小团毒雾，把中毒传给附近 2×m 只（不连锁） |
| 火种 | 点燃的怪死后向周围溅火，点燃附近 2×m 只（不连锁） |
| 裂隙之眼 | 怪身上同时有 3 种以上标记 / 状态时，立刻「过载」：受到 15×m 伤害并清空所有标记（同一只 3 秒一次） |

### 4.6 兵器系宝物 / 突破钥匙：**取消**（11/26）
- 取消技能「突破」（Lv8），Lv7 就是技能最终形态；后期成长只靠**转职**。不做「职业信物」。原各系宝物删除。

### 4.8 删除的旧宝物
护身符（生命 +20，交给防具）、轻便靴（移速，交给词条）、磨刀石（全伤害 +10%，纯数值）、沙漏（出手速度，交给词条）、原来各系「伤害 +%」宝物（改为突破钥匙）。存档里的旧宝物按价格退成铜钱。

## 5. 实现提示（给 Codex）
- 词条按「标签」生效：技能数据要先加 `tags` 字段（斩 / 刺 / 射 / 火 / 冰 / 雷 / 奥术 / 数码…）。
- 标记几率类：每个技能每次释放最多触发 1 次，副弹 / 追加伤害不触发。
- 属性上限在最终结算时统一夹住。
