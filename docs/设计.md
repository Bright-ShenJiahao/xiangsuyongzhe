# 《像素勇者》游戏设计（第一版，2026-11-21 讨论稿）

> 11/21 讨论定稿。数值（波数、敌人数、掉落数、价格）都是起始值，玩起来再调。

## 1. 故事与结局
- 深夜两点，主角还在打一台旧游戏机，屏幕一亮，人被吸进了游戏里。
- 游戏里是一盘卡带的世界。打倒最后的首领 = 通关这盘卡带 = 回到现实。
- **一局有头有尾**：走完固定的站数、打倒首领就结束，输了就从头再来。

## 2. 一局的流程
```
主界面 → 选起手兵器（剑 / 枪 / 弓 / 法杖）→ 准备页
  → 第 1 站：进地图 → 第 1 波 → 波间结算 → 第 2 波 → 波间结算 → … → 最后一波 → 波间结算
  → 「下一步去哪」（2–3 张选项卡）→ 第 2 站 → …
  → 第 8 站之后：首领站 → 通关结算
```
- 第一版：**8 站 + 首领**，约 15 分钟一局。只做第一章（新手村 · 打谷场，哥布林，首领哥布林王）。
- **没有局外成长**：每局从零开始，不攒任何东西到下一局。

## 3. 起手兵器（开局四选一，不锁定）
| 兵器 | 起手招 | 攻击形状（幸存者式：大、看得清、往外甩） |
|---|---|---|
| 剑 | 横斩 | 身前大扇面横扫 |
| 枪 | 突刺 | 长直线突刺，穿透一排 |
| 弓 | 速射 | 远程直线箭，射最近的敌人 |
| 法杖 | 火球 | 砸向远处敌群，落地炸一圈 |

- 选的只是**起手招**（放在技能第 1 格）。之后技能书**任何系都会出**，可以剑招、法杖招混着带。

## 4. 一站怎么打
- 进地图后一波一波打，**一波不限时，杀完这一波就算清**，然后进波间结算。
- 每站几波：普通战斗 3 波；精英 3 波（最后一波带精英怪）；首领站 2 波 + 首领。
- **前期每波人少、波短**：敌人数量随站数往上涨，第 1、2 站每波只有少量哥布林，让玩家先熟悉；后面几站再加刀手、弓手和数量。
- 战斗中**随时可以按暂停**，暂停页可以进「技能」页调整搭配。
- 战斗中拿到技能书：放进背包，屏幕角上提示「获得技能书」，**不强制暂停**。

## 5. 波间结算页（参考三国终章打完一仗的整备页）
上面一排分页，从左到右：

| 分页 | 内容 |
|---|---|
| 结算 | 这一波击倒数、铜钱、经验；**输出统计**（每招打了多少、占百分之几，照三国） |
| 拾取 | 这一波掉的技能书、宝物：「学会 / 收下」或「卖掉换铜钱」；没处理的出发时自动卖掉 |
| 修炼 | 升级攒下的修炼机会：每次三选一加属性（见第 7 节） |
| 行商 | 每次摆 4–5 样货，可以买多件；花铜钱刷新、越刷越贵；可以锁一件留到下次 |
| 技能 | 技能搭配页：5 个格子、背包里的技能书、每招说明、一轮出手要多久 |

- 右下角「继续」开下一波。这一站最后一波后，「继续」变成「下一步去哪」。
- 手机竖屏：分页改成可左右滑的一排，内容一页一屏。

## 6. 「下一步去哪」（参考月圆之夜，不用路线图）
- 一站打完，弹 2–3 张选项卡，每张写清楚去哪、有什么奖励，玩家点一张就去。
- 画面上一直显示「第 n / 8 站」，走满 8 站后只有一张「首领」卡。

| 卡 | 内容 | 奖励 |
|---|---|---|
| 战斗 | 3 波普通敌人 | 经验、铜钱、战利品（见第 8 节掉落） |
| 精英 | 3 波 + 精英怪 | 必掉一本好技能书 + 宝物 |
| 宝箱 | 不打，直接开 | 宝物或技能书二选一 |
| 休息 | 不打 | 回 40% 生命，或给一招升级 |
| 首领 | 第 9 站 | 通关 |

- 行商不单独占一站，每次波间结算都能逛。

## 7. 成长（只在这一局里）
### 升级
- 打怪攒经验，**升级不弹框**，自动加少量基础属性（生命、伤害）。
- 每升一级攒一次「修炼」机会，在波间结算的「修炼」页三选一加属性（照三国：卡有普通 / 精良 / 稀有 / 绝世，每次可刷新 2 次）。

### 属性（四项，对应四系）
| 属性 | 作用 |
|---|---|
| 力量 | 剑、枪招式伤害 |
| 敏捷 | 弓招式伤害、出手速度 |
| 智力 | 法杖招式伤害、技能范围 |
| 体魄 | 生命上限、受伤减免 |

### 宝物（被动）
- 来源：精英、宝箱、行商。例：伤害 +、出手更快、范围更大、移速、拾取范围、每波回血、首次受伤免伤等。

## 8. 技能：自动、按顺序放（参考三国终章「上阵武艺」）
- 技能槽**最多 5 格**，**开局开 3 格**，第 4、5 格靠奖励或行商「开新槽」打开。
- 技能按 1 → 2 → 3 → … → 1 的顺序轮流自动放出；每招有起手和收势时间，搭配页显示「一轮出手总时长」。
- 技能书只从战利品和行商来，**升级不给技能**。掉落照三国终章（起始值）：
  - 每站最后一波打完，「拾取」页出战利品：普通战斗 1 本（25% 两本），精英 2 本 + 1 件宝物，首领 2 本 + 1 件宝物。
  - 前两站不另掉技能书，只有起手那一招，先熟悉。
  - 行商每次 3 件宝物 + 2 本技能书，价格随站数涨；没买的可以锁一件留到下次。
  - 中间几波的「拾取」页只有铜钱和偶尔的消耗品。
- 拿到已有招的书 = 这招升一级（只涨伤害，少量加快；范围不随等级涨）。
- 招式内容先占位，每系 1–2 招跑起来再说。

### 照搬三国终章的规则（docs 见旧仓库 `docs/武艺设计规则.md`）
1. 越强、范围越大，出手越慢；同一档内每秒伤害大致持平，差别放在形状和状态上。
2. 每招单独带也好用，招与招之间不做联动，不能出现「两招一起带反而变差」。
3. 状态只用少数几种：破甲、流血、眩晕、迟缓、灼烧；精锐、首领对控制减半或免疫。
4. 普通命中敌人不停步，只闪白、推一下；只有眩晕让敌人停下。
5. 画面分级：低档朴素，越高档越华丽。
6. 攻击形状照幸存者类往外甩，不按兵器的真实长度判定。

## 9. 敌人（第一章）
- 小怪：哥布林、哥布林刀手、哥布林弓手；精英：放大的刀手 / 盾兵（素材来自《异世界幸存者》，已有全套动作）。
- 首领：哥布林王（跺地、冲撞、喊小弟）。
- 第二、三章以后再说（异世界里还有狼骑、萨满、炸弹兵、巨人、哥布林皇帝可用）。

## 10. 界面清单（手机竖屏、电脑横屏都要能用）
1. 主界面（深夜房间，已有）
2. 选起手兵器（四张卡）
3. 准备页（看起手招、属性，点出发）
4. 战斗 HUD：生命、经验、波数「第 2 / 3 波」、站数「第 3 / 8 站」、技能槽一排（亮起的是正要放的那招）、背包新书提示、暂停
5. 暂停页：继续 / 技能 / 回主界面
6. 波间结算页（结算 / 拾取 / 修炼 / 行商 / 技能）
7. 下一步去哪（选项卡）
8. 通关 / 阵亡结算

## 11. 第一版不做
- 局外成长、多个章节、奇遇事件、技能数值平衡、新美术（全部用现有素材和代码画的特效）。
